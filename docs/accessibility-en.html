Accessibility

We want everyone to be able to use this site.

Scope and standard

This statement applies to the website Chemotion Converter – Readers & Profiles Index. The site is designed to meet the Web Content Accessibility Guidelines (WCAG) 2.1, level AA. A formal audit has not yet been carried out.

Implemented measures

  • Semantic page structure with landmarks, a logical heading hierarchy and a "skip to main content" link.
  • All functions can be operated with the keyboard; focused elements are clearly highlighted.
  • Text and interactive elements meet a contrast ratio of at least 4.5:1 in light and dark mode.
  • Light and dark mode follow the operating system; animations are reduced if "reduce motion" is enabled.
  • Layout adapts to small screens and to zoom levels up to 400 %.
  • System fonts are used, so your own font settings apply.
  • Besides the interactive tables, every reader and profile is also listed in a plain HTML list that works without JavaScript and with screen readers.

Known limitations

  • The interactive tables (AG Grid) are complex widgets. They support keyboard navigation and ARIA roles, but can be tedious with a screen reader – please use the plain lists below each table.
  • The overview document about.pdf and its images are diagrams without a full text alternative. Its content is described in the "How it works" section of the start page.
  • The "check explanation" column is generated automatically with a language model and may be imprecise.
  • Downloadable profiles (JSON) and reader source code (Python) are technical files and are not adapted for accessibility.

Feedback and contact

If you encounter barriers on this site, please contact us using the details in the imprint. We will try to remove the barrier or provide the information in another way.

Further information

The accessibility statement of the Karlsruhe Institute of Technology, including information on the enforcement procedure, is available at kit.edu/erklaerung-barrierefreiheit.php.
