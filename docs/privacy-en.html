Privacy policy

In short: no cookies, no tracking, no third-party content.

1. Controller

The controller responsible for this website is named in the imprint. General information on data protection at the Karlsruhe Institute of Technology (KIT), including the contact details of the data protection officer, is available at kit.edu/datenschutz.php.

2. Hosting on GitHub Pages

This website is a static site hosted on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. When you open a page, your browser necessarily transmits technical data to GitHub's servers, in particular your IP address, the date and time of the request, the requested file, the referrer URL and the browser identification (user agent). GitHub processes this data to deliver the website and to ensure its security and stability; GitHub may also process data in third countries such as the USA.

We have no access to these server logs and do not evaluate them. Further information: GitHub General Privacy Statement.

3. No cookies, no local storage, no tracking

  • This site sets no cookies and writes nothing to your browser's local or session storage.
  • There is no web analytics, no tracking pixel, no advertising and no social media plugin.
  • Light and dark mode follow your operating system setting; no preference is stored.

4. No third-party content

All fonts, stylesheets, scripts and images are delivered from this website itself. No content delivery network (CDN), no external web fonts (e.g. Google Fonts) and no externally embedded media are used, so opening this site does not transmit any data to third parties besides the hoster.

The only third-party software component is the table library AG Grid Community 36.2.0 (MIT license, AG Grid Ltd.). It is stored on and served from this website and runs entirely in your browser; it does not contact any external server.

5. Downloads and external links

Profiles, reader source code and documents offered for download are served from this website. Links to external websites (e.g. GitHub, chemotion.net, kit.edu) are ordinary hyperlinks: data is only transmitted to the respective provider once you click such a link. The privacy policy of the linked provider applies there.

6. Data processed when the site is built

When this site is generated (not when you visit it), the build process retrieves ontology labels from the EBI Ontology Lookup Service (OLS). No visitor data is involved in this step.

7. Your rights

Under the GDPR you have the right to access (Art. 15), rectification (Art. 16), erasure (Art. 17), restriction of processing (Art. 18), data portability (Art. 20) and to object (Art. 21). As we do not store any personal data of visitors ourselves, requests regarding server logs must be directed to GitHub. You also have the right to lodge a complaint with a supervisory authority, for example the State Commissioner for Data Protection and Freedom of Information Baden-Württemberg.
