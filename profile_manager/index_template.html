Why the Converter

One converter for the whole lab

Laboratories produce data in dozens of proprietary and semi-structured formats. The Converter reads them, understands their structure and writes standardised, machine-readable files that the Chemotion ELN, ChemSpectra and other tools can use directly.

  • Readers for many formats

    Python reader classes parse CSV, TXT, Excel, XML, PDF and vendor-specific binary files (e.g. Gamry DTA, Metrohm NOVA, BioLogic EC-Lab, Bruker, Malvern Panalytical) into tables and metadata.

  • Profiles instead of code

    A profile is a JSON rule set: it recognises a file by its identifiers and maps columns, units and metadata to the output. Profiles are created in a graphical editor – no programming needed.

  • Standard output formats

    Results are written as JCAMP-DX (.jdx), as a BagIt ZIP container with checksums, as RDF/Turtle (.ttl) or as metadata JSON – ready for archiving and re-use.

  • Ontology-aware

    Profiles can carry terms of the Chemical Methods Ontology (CHMO). The index below resolves them via the EBI Ontology Lookup Service, so every profile is linked to the measurement method it describes.

  • Data operations

    Profiles can transform x/y values with column, constant, metadata or header based operations and repeat output tables in loops for multi-table files.

  • Versioned & migratable

    Profiles are versioned and can be restored. Built-in migrations keep older profiles compatible when the profile format evolves.

How it works

From raw file to standardised data in four steps

  1. Upload

    A file arrives – dropped into the ELN inbox, sent by a measurement device, posted to the REST API or passed on the command line.

  2. Match a reader

    Each reader's check() decides whether it can parse the file. If several fit, the lowest priority value wins.

  3. Match a profile

    The parsed tables and metadata are compared with the identifiers of all profiles to find the right rule set.

  4. Write output

    The profile maps the data to JCAMP-DX, BagIt ZIP, RDF or JSON – including units, metadata and ontology terms.

Integrated

Built into the Chemotion ELN

In the Chemotion ELN the Converter works as a background service. When a user or a measurement device uploads an analytical file, it is converted automatically – the user only notices the additional, converted files next to the original.

  • Automatic conversion on upload, no manual export steps
  • Converted results appear in the inbox next to the original file and can be attached to analyses
  • JCAMP-DX output can be inspected and processed with ChemSpectra
  • Admins manage profiles in the ELN under Converter Profiles and can delegate profile editing to individual users
  • Works with Chemotion LabIMotion

Standalone

Just as powerful on its own

The Converter does not need an ELN. Install it with pip and use it on your workstation, in your own data pipelines or as a central conversion service for your institute. On first start the standalone mode downloads the public profile set automatically.

  • Desktop GUI

    Starts a local server and opens the converter and profile editor in your browser at http://127.0.0.1:5000.

    python -m converter_app
python -m converter_app edit-cli-profiles

  • Command line

    Convert files from shell scripts and data pipelines. Output types: jcampzip, jcamp, rdf.

    python -m converter_app convert \
  -i measurement.csv -o jcampzip

  • REST server

    Flask app served by gunicorn behind NGINX, with HTTP basic auth to separate clients. Endpoints include /conversions, /tables, /profiles, /datasets and /options.

    Server setup guide →

Installation (Python 3.12 or newer, Linux or macOS; on Windows use WSL2):

python3.12 -m venv .venv && source .venv/bin/activate
pip install git+https://github.com/ComPlat/chemotion-converter-app

Pre-built standalone apps for Windows and Linux are coming soon.
